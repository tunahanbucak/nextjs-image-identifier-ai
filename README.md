# Google's Gemini AI ile Güçlendirilmiş Görüntü Analizörü

Google'ın Gemini AI'si ile güçlendirilmiş son teknoloji Görüntü Analizörü ile tanışın! Bu araç, fotoğraflarınızdaki nesneleri, sahneleri ve kişileri tanımlar, araştırma ve keşif için detaylı bilgiler sunar.

## 🔥 Özellikler:

- **Fotoğraflarınızdaki nesneleri, sahneleri ve kişileri tanıyın**
- **Görüntü içeriği hakkında detaylı bilgiler** sunun
- **Daha fazla araştırma için anahtar kelimeler** önerin

## 💡 Nasıl çalışır:

1. **Herhangi bir görsel yükleyin**
2. Yapay zeka, **saniyeler içinde** analiz eder
3. **Anında, detaylı sonuçlar** elde edin!

## 🛠️ Kullanılan Teknolojiler:

- **Next.js 14**
- **TypeScript**
- **Tailwind CSS**
- **Google Gemini AI**

## 📂 Kurulum:

Projeyi yerel bilgisayarınızda çalıştırmak için şu adımları izleyin:

### 1. Depoyu klonlayın:

```bash
git clone https://github.com/tunahanbucak/nextjs-image-identifier-ai.git
```

### 2. Bağımlılıkları yükleyin:

```bash
cd nextjs-image-identifier-ai
npm install
```

### 3. Projeyi çalıştırın:

```bash
npm run dev
```

Bu, projeyi yerel olarak `http://localhost:3000` adresinde başlatacaktır.
